# Examples

## Minimal card

```yaml
type: custom:family-calendar-card
instance: main
```

## Three-day timeline, locked

```yaml
type: custom:family-calendar-card
instance: hallway
days: 3
layout: timeline
start_hour: 6
end_hour: 22
event_style: filled
```

## Custom icons

```yaml
type: custom:family-calendar-card
instance: main
icon_keywords:
  karate: mdi:karate
  swim: mdi:pool
```
